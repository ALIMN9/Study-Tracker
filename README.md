# Study Tracker

A Java console application for tracking subjects and study sessions.

## Features

- Add subjects
- View subjects
- Add study sessions
- View study sessions
- Search subjects
- Track total study time
- Remove subjects

## Technologies

- Java
- Object-Oriented Programming
- ArrayList
- LocalDate

## Future Plans

- Improve the project architecture
- Add a database
- Build a Spring Boot REST API
- Create a web interface
